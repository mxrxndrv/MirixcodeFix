Comment héberger sur GitHub Pages gratuitement ?

            

            
            
    
                
  1. 
                    Crée un dépôt GitHub : Va sur github.com/new et nomme ton projet (ex: codefix-ai).
                
    2. 
                
  2. 
                    Télécharge le Pack CodeFix AI : Clique sur le bouton "Pack GitHub" en haut de cette page pour télécharger l'archive zip avec tous les fichiers prêts.
                
    3. 
                
  3. 
                    Ajoute les fichiers : Glisse-dépose le fichier index.html, SYSTEM_PROMPT.md et README.md dans ton dépôt GitHub.
                
    4. 
                
  4. 
                    Active GitHub Pages : Dans ton dépôt sur GitHub, va dans Settings > Pages, sélectionne la branche main (dossier root) et sauvegarde.
